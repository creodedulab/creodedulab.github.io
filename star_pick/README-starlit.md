# 별의 선택

`index.html` 또는 `starlit.html`을 Chrome / Edge에서 열어 실행합니다. 설치와 서버, 인터넷 연결이 필요 없습니다. HTML과 `starlit.css`, `starlit.js`를 같은 폴더에 보관하세요.

1. 번호 범위 또는 쉼표·줄바꿈으로 구분한 이름을 입력합니다. 참가자는 2~200명, 팀은 2~24개까지 지원합니다.
2. **카드 섞기 페이지로**를 누르면 설정 화면에서 섞기 화면으로 이동합니다.
3. 구슬 위에서 마우스나 손가락을 움직이거나 **마법으로 팀 만나기**를 누릅니다. 구슬에 키보드 초점을 맞춘 뒤 Enter / Space를 눌러도 됩니다.
4. 주문 연출 후 별도의 결과 페이지에서 팀별 카드가 공개됩니다. 연출 건너뛰기는 이미 배정된 동일한 결과를 보여줍니다.
5. 결과를 복사하거나 PNG 이미지로 저장할 수 있습니다. 복사가 제한된 환경에서는 텍스트 파일을 저장합니다.

오른쪽 위 음악 버튼으로 소리를 켜고, 옆 설정 버튼에서 음악·효과음·주문 음성과 음량을 조절합니다. 음악은 기본 켜짐이며, 화면을 열면 자동 재생을 시도합니다. 브라우저가 자동 재생을 제한하면 첫 클릭·터치·키 입력 시 시작합니다. 음악 버튼으로 직접 끈 경우에는 그 상태를 유지합니다. 기본 음량은 65%입니다. 배경음악과 효과음은 Web Audio로 합성하며 외부 음원을 사용하지 않습니다. 주문 음성은 브라우저/운영체제의 한국어 음성 지원 여부에 따라 다릅니다. 음성 없이도 모든 기능을 사용할 수 있습니다.

번호·이름은 서버로 전송하거나 영구 저장하지 않습니다. 중복 이름은 독립된 참가자로 처리합니다. Web Crypto의 난수를 사용한 Fisher–Yates 셔플 후 순서대로 팀에 배정합니다. 팀 인원 차이는 최대 1명입니다. 나머지 인원은 앞 번호 팀부터 한 명씩 배정됩니다.

`node verify-starlit.cjs`로 로컬 Chrome에서 기능과 화면을 검증합니다. 테스트는 Windows의 기본 Chrome 설치 경로를 사용합니다. 스크린샷은 `screenshots/starlit-*.png`로 저장됩니다.

화면은 설정(`#setup`) → 카드 섞기(`#mix`) → 결과(`#results`)의 세 페이지로 구성됩니다. 한 번에 한 페이지가 표시되고, 페이지를 이동해도 음악과 참가자 정보가 유지됩니다. 팀 이름은 1팀, 2팀 등 숫자로 표시됩니다. 참가자 미리보기·섞기 카드·결과 카드의 번호와 이름을 크게 표시하며 긴 이름은 줄바꿈합니다.
